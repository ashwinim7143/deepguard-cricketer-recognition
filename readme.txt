AI-Based Cricketer Recognition System Using CNN

Files:
- cricketer_cnn_project.py : complete training + prediction code
- cricketer_dataset.csv : supplied dataset
- requirements.txt : required libraries

Run:
1. pip install -r requirements.txt
2. python cricketer_cnn_project.py

For a new photo, place it in the folder and run:
predict_cricketer("new_cricketer.jpg")

Accuracy is calculated when the model is trained; it should not be assumed in advance.
